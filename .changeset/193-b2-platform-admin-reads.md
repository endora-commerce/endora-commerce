**Side-table loaders on the admin `?extensions=` read** (`specs/193-admin-form-extensions/` WP-B2, FR-015, ruling D-300.1; 187 R-17).

- `EntityExtensionLoaderEntry` gains an optional `adminReads?: boolean`. A loader registered with `ctx.entityExtensionLoaders([{ host, schema, load, adminReads: true }])` is also served by `schemaExtensionReads` on its host's admin detail and list reads under `extensions.<moduleId>`: called once per response with the records' ids on the route's entity manager, every value parsed with its schema (`EntityExtensionLoaderOutputError` on a refusal), `null` on a record without a value. Each value must be an object keyed by field, or `null` (ruling D-300.24); anything else — an array, a string, a number, a boolean — fails the read with `EntityExtensionLoaderOutputError`. A loader without `adminReads` keeps any value type on the read ports. Without `adminReads`, or while the module is switched off, the key is omitted and the loader is not called; a key no module serves is omitted, never `422`. A loader without `adminReads` behaves exactly as before.
- New loader-registration refusal `loader-and-columns-on-one-host` (`EntityExtensionInvalidError`): a loader with `adminReads: true` from a module that also declares `adminReads` D2 columns on the same host table. `EntityExtensionLoaderRegistryOptions` gains `columnExtensions`, the column declarations it is judged against; `RegisteredEntityExtensionLoader` gains `adminReads`.
- `createSchemaExtensionReads` takes an optional `loaders` (the loader registry); `composeApp` passes it, and the column declarations to the loader registry.
- New on `./db`: `recordedSchemaExtensions()`, the column declarations the ORM configuration recorded, throwing when none has recorded them yet (D-300.23). It is the reader `composeApp` hands the loader registry, so a composition that registers modules before configuring its ORM fails loudly on its first `adminReads` loader instead of skipping `loader-and-columns-on-one-host`.
- **Type widening**: `ExtensionAttributeMap`'s per-module value is now `Record<string, ExtensionJsonValue> | null` — `null` for a served module with no value for the record (D-300.25). Code that indexes into a module's attributes checks for `null` first.
