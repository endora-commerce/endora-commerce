# CMS

> **Status**: under construction (feature 014). This page is populated in Phase 10 polish (T098).

The CMS module owns Pages, Blocks, Templates, and storefront Hooks, all
authored through a drag-and-drop Page Builder (Puck). The module is the
platform's editorial surface; other backend modules contribute additional
Page Builder components through the registration SPI in
`backend/src/modules/cms/services/page-builder-registry.ts`.

Detailed documentation lands here once the implementation is end-to-end
functional.
