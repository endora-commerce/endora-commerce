# Assets Library

> **Status**: under construction (feature 013). This page will be populated
> in Phase 9 (T104) once the module is end-to-end functional.

The Assets Library is the platform's digital-asset substrate. It owns:

- A central catalogue of files (images, video, PDFs, documents) reusable across
  Product media, Product attachments, Category main images, and CMS pages.
- A folder tree for organising assets.
- Pluggable storage backends — Local filesystem, Amazon S3, GCP Cloud Storage —
  configured from Settings, exactly one active at a time.
- Public/private visibility per asset.

Detailed configuration, admin guide, and API reference will land here as the
implementation progresses.
