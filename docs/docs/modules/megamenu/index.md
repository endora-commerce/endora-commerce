# Megamenu

> **Status**: under construction (feature 015). This page is populated in Phase 10 polish (T085).

The Megamenu module owns the storefront's primary navigation. It introduces a tree of menu items (Category links, CMS-page links, External links, Buttons, Assets, embedded CMS Blocks), authored through a drag-drop admin editor and rendered server-side on Next.js with a hover-revealed full-width drop-down panel on desktop and a stacked drill-down drawer on mobile. Configurations are scoped to `(salesChannelId, language)` pairs with a partial unique index enforcing "exactly one active megamenu per scope."

Detailed documentation lands here once the implementation is end-to-end functional.
